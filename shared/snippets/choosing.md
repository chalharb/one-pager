## Choosing between similar blocks

- **Understand or find?** A reader learning how something works gets the
  explainer (or report) shell. A reader looking things up gets the directory.
- **Options against the same criteria** → comparison. **One option's details**
  → facts.
- **Label / value pairs** (owner, version, cost) → facts. **Words to define** →
  terms.
- **Order matters** → steps. **Order doesn't** → point list. **Dates or
  phases** → timeline.
- **Two to four numbers that are the point** → stat row. **A pattern across
  many numbers** → chart. **One number** → say it in the text.
- **A flow, sequence or structure** → diagram. **Amounts or a trend** → chart.
  Never both for the same idea.
- **The one thing not to miss** → callout, once per page. If everything is
  important, nothing needs a callout.
- **Nothing fits** → a plain paragraph or list. Don't invent markup or CSS;
  tell the user which block was missing.
